# 去玩 — 数据库设计文档 v14（最终版）

## 核心约束
- 禁止浏览器原生弹窗(prompt/alert/confirm)，用 ConfirmDialog/BottomDrawer
- user.id=UUID(外键), user.numeric_id=数字(展示)
- 时间字段统一 timestamptz
- 延迟发号：signUp不加ID，complete_registration成功才取

## 表（13张）
profiles, id_generator, invite_codes, activities, activity_sessions, bookings, group_members, group_messages, notifications, messages, records, saves, follows

## RPC（13个）
| 函数 | 说明 |
|------|------|
| get_login_email | 昵称/ID→邮箱 |
| complete_registration | 验证邀请码→取号→设昵称→记码 |
| set_user_role | 超管设角色 |
| generate_invite(max, note) | 管理员生成邀请码+备注 |
| update_profile | 本人改资料 |
| admin_reset_password | 超管重置任意用户密码 |
| approve_booking | 审核预约(create→confirm/reject) |
| review_activity | 审核活动→通过自动建群拉发布者 |
| cancel_session | 取消期次→删期次+退预约 |
| close/reopen_activity | 关闭/重开活动 |
| set_featured | 推荐位 |
| cancel_booking | 本人取消预约 |
| toggle_save/follow | 收藏/关注 |

## 生命周期
活动: pending_review→active/rejected→草稿箱→编辑重提→pending_review→active→closed
期次: 无status字段,状态由时间段判定(upcoming/booking/wait/ongoing/completed)
预约: pending→confirmed/rejected/cancelled

## 群聊
- 审核通过自动建群(发布者加入)
- 预约确认后用户自动入群
- 群消息存 group_messages 表，持久化

## RLS 要点
- notifications: authenticated 可插
- group_members: 发布者/管理员/本人可插，全员可读
- bookings: 仅本人可插 pending，不限制超管
